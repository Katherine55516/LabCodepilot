## 实施范围

- 页级内容模型先定义读者问题、增量消息、类型化关系、比较集合和来源义务，再选择能容纳实际内容的模板槽位。相关短单元共享一页，不按源码段落数或 sourceUnitId 数机械分页。
- 比较表在 overview 中也必须保留比较功能；禁止多候选比较表退化为单行，却仍使用总览标题。用户明确的过滤条件保留，完整原表进备注。
- 补漏回到所属章节；closing 不承担无关新事实。保留 stable ID、唯一主讲归属和局部修复边界。
- 数学内容保持自然文字比例、可读对比和解释关系；原生字体/字号保真，不能通过缩字掩盖容量不足。
- 明确输出语言在规划、metadata 修复和 writer 中一致；可见正文不写“本页将解释/来源已覆盖”等生成过程话术，来源备注不反复占据主稿空间。
- ASCII 架构/流程等非程序围栏须分类为语义结构，不能因 code=omit 被当成程序代码整体隐藏。来源中的并行/对比/流程不得相互混淆。
- 对已确认/推断/未知等证据标签建可见承载关系，既不能抹除限定，也不能以模型自己写的总结证明事实。
