## 审核和实施

- [x] 建立原型主要动作与产品验收矩阵，区分真实功能、模拟原型行为与现有生产增强。
- [x] 项目与文件夹手动排序：独立于 Pin、同组拖拽、持久化、失败回滚与跨设备读取。
- [x] 粘贴/文件输入在模型确认后使用现有服务端 outline DAG 生成可编辑大纲；移除“本地规则大纲冒充 AI 读取”的路径，保持页数和模板选择可编辑。
- [x] 编辑器文件名与内容标题分离、保存位置保持、未发布退出的保留/放弃/取消，以及导出保持编辑上下文。
- [x] 校对新建、导入、模板、版本更新、任务和生成阶段的入口、按钮、页数、预览与错误反馈。
- [x] 三语编辑器退出文案、后端自检、单元测试、浏览器桌面与窄屏交互验收，记录未覆盖的实际环境条件。

## 决策

- 原型中的纯模拟下载或假 AI 不作为生产实现；用既有真实接口完成相同用户动作。
- 手动排序以项目/文件夹的持久 `manualOrder` 记录，Pin 单独排序；旧记录按现有创建时间稳定回填排序。
- 文本与文件大纲沿用现有持久化项目的 outline 节点，不新增后台阶段。
