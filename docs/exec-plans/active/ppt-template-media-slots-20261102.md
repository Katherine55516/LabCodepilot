# PPT 上传模板媒体：槽位规则、图片读取与不重复

> 创建时间：2026-11-02
> 最后更新：2026-11-02

## 背景

用户反馈：使用 `/templates` 的模板生成时，媒体大量消失、重复，也没有根据页面风格生成新的媒体。审计结果如下：

- Mood-Board 的 MCP 稿：20 个内容页中 22 页没有任何图片；模板 10 张画中只保留 2 张。
- Portfolio 稿：36 个内容页中 30 页没有图片，模板箭头图片在第 12/14/16/31 页重复。

根因：
1. 没有图片读取器。vision_reader 路由被策略禁止，系统也没有安装 tesseract，所以模板画作被当成"旧样例内容"全部退役。
2. 内容页集中在两三个高容量模板页上，版式复用上限没有生效。
3. 10-31 规则禁止模板照片出现在内容页。
4. 被退役的槽位没有替代内容。
5. 没有限制同一张图片重复出现。

用户要求：先由 Claude 与 Fable 不经 PPT 模块、手工制作一份 world_models × Mood-Board 的演示稿，再据此决定方案。15 页手工稿见 scratchpad `wmhand/world-models-mood.pptx`。用户于 2026-11-02 确认了下文的决策。

## 决策（Fable 决定，用户确认）

- **槽位规则（取代 10-31 规则）**
  - 外框槽位：图片贴着页面边缘，且宽或高至少占页面的 25%（横幅、半出血画、封面主图）。所有页型都保留经过认证的画作，不留空。
  - 内容槽位：只放该页引用的源文图表。内容页的内容槽位不放画作。
- **图片读取（三层）**
  - A：新增角色 `template_picture_reader`，与 vision_reader 分开。首次使用时向配置的模型发送一张合成小图，测试它能否识别图片，结果按 (configId, model) 缓存。
  - B：内置 tesseract.js（eng + chi_sim）。
  - C：用 sharp 做像素分析。
  - 认证等级：L1 = 无文字且非图表/界面；L2 = L1 加上无人物（只有 A 能判断）。只有像素分析时不认证。只有数字的识别结果记为 numbers_only。
- **template_numbered_artwork**（花瓣、圆环等带数字的图形）：要点数与槽位数一致时保留，否则整组退役。
- **版式复用上限** max(2, floor(N/5))，作为成本计入；全部超限时用次数最少的版式，并记录警告。
- **图片不重复**
  - 每张画在一份稿中最多出现一次。
  - 同尺寸的画全部用完后，才允许第二次使用，且相隔至少 5 页。
  - 之后外框槽位改用模板深色的纯色横幅或面板。
- **源文图表提取**
  - 裁剪框限定在图形本身，不带正文栏，也不带查看器图标。
  - 图表、截图、界面用 contain 适配，游戏画面用 cover 适配。
- **去除生成器标记**（Made with Gamma、Canva 等），并记入台账。
- **其他规则**
  - 原生槽位文字至少 12 pt。
  - 图形内的标签槽做容量检查。
  - 每个内容页都要有视觉元素。
