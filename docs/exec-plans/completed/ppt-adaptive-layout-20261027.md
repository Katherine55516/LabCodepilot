## 2. 方案与取舍

采用“来源与组件语义 → 完整候选布局 → 真实测量 → 评分选择 → 共享IR → Canvas/原生导出验证”。

- 模型提供页面目的、内容关系和读图结论；代码负责坐标、完整来源、容量、原子组、对齐和碰撞。避免让模型随意输出像素坐标。
- 同时比较图上文下、文左图右、整宽图注、规则卡片、纯正文/章节等候选；不把第一个能放下的候选当最优。
- 图片只做等比例缩放。允许放大，显示源图清晰度限制；不裁掉科学图、表头或图中文字。图注与正文完整测量，不能隐性截断。
- 卡片统一同排高度、间距、内边距；三个步骤优先同排或完整等宽网格。狭窄页面使用有明确阅读顺序的两行，而不是任意高低错落。
- 对有共同原生组、同位互补遮罩/几何的媒体建立原子组。一组只能整体保留并等比例变换，或在design-only政策下整体退休；不保留半个圆环。缺乏证据的陌生图片不强行合并。
- 没有对应来源/说明的圆环是装饰，不能暗示比例、步骤数或虚构右侧内容。正文需要空间时整体退休，或放在有明确用途、可读的装饰区；不为了填右侧留白编造文字。
- 标题按用途规划：正文/图页优先页顶安全带；章节页可有意居中，但不与导航内容和装饰冲突。模板样式沿用，模板旧坐标不凌驾于可读性。
- 已有人为位置调整、显式锁定、固定品牌/来源证据的对象不自动移动或删除；冲突给出具体原因，保留原稿。每次重排记录原/新几何、候选和选择依据。
- 同一规范节点与共享渲染合同负责Canvas、SVG、PPTX/PDF，不能只修浏览器CSS。

## 3. 推荐实施顺序

1. **P0 媒体原子性和空容器**：原生图层组合识别、整组处置；修空内容框检测。先保证不出现残缺媒体或无绑定框。
2. **P1 图片/图注候选**：单图优先比较整宽图下文，放大可读图面；多图保持各自完整图注和阅读顺序。
3. **P1 卡片与标题几何**：填框后按来源顺序排成规则网格；同排等高，整体居中；正文/图页使用页顶标题模板。
4. **P1 评分与诊断**：完整性/安全边界为硬约束；图面面积、图注宽度、对齐、阅读顺序、空白平衡为软评分。装饰不能为了“保留率”强占中心。
5. **P1 真实回归**：对截图对应C6、W12/13/15以及相同input生成稿逐项比对；同时完成111项的内容、公式和检查器回归。

## 4. 验收标准

- 圆环和互补图层不分裂、不单独缩放，无无内容的中心数据装饰。
- 单图等比例放大，完整图注可在图下使用较宽文本框；来源实际分辨率/宽高比保持一致。
- C6三个容器按阅读顺序规则排布，同排顶/底对齐、等高；文字不遮挡，其他9页内容不改变。
- 普通页标题与图文不重叠，位于设计的页顶区域；章节标题布局有明确结构用途。
- 生成、重排、局部编辑、发布、Canvas与原生导出共用相同坐标；原生对象仍可编辑。
- 保留全部结果表数据、公式时间条件和解释；不靠删文、缩字、乱加装饰或关闭检查器换取“好看”。
- 锁定/手工位置负例、拆半媒体负例、窄图注负例、超容量负例均有直接测试；记录实际失败及修复，不用模拟通过代替真实验收。
