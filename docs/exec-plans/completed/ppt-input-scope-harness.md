## 决策

- 输入和用户明确给出的材料是事实与主题边界；模型生成的 brief、来源引用 ID、模板、详细模式和编辑指令不能自行扩大边界。
- 允许必要的框架内解释，禁止无材料支持的具体事实及新增主题；密度不足以合并、减少页数或显式报告不足解决。
- 不用关键词相似度充当语义真实性验证；要求完整可见内容、原始输入、逐页范围审查与版本绑定。模型审查仍有误判可能，报告须明示。
- 保持产品 workflow/UI 不变；共享四类 critic findings，并增加必须完成的 scopeAudit。局部 AI 内容候选在保存提案前审查，导入 PPTX 不得跳过 AI 后的审查。

## 验收

短 prompt、长文、双语、表格/代码/流程、框架内解释与无数字的越界话题均有覆盖；缺失/伪造/过期审查不能发布；来源、prompt、政策变化失效缓存；运行 backend 自检及 npm test。保留此前未提交修改。

31 个 PPT backend 自检成功，新增 14 组范围场景；npm test 2,808 pass / 0 fail / 1 skip。M2 宿主 PDF 子检查缺 matplotlib 跳过。真实模型语义准确率未测；见 research/ppt-input-scope-harness-review-20261008.md。
