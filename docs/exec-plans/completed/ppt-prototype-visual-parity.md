# PPT 原型视觉对齐

> 创建时间：2026-09-23
> 最后更新：2026-09-24
> 状态：已完成（本地视觉与自动化验收）

## 目标

对照 `prototype.html` 的配色、字体、密度和布局，对齐 PPT 工作区、新建流程、模板、生成、编辑界面。仅修改展示层和响应式规则；保留现有 Cowork、Run/DAG/Event、IR、命令日志、质量门禁及导出。

## 执行与验收

- [x] 核对原型深浅色视觉变量与应用组件的差异。
- [x] 在 PPT 模块内建立作用域明确的视觉变量，不覆盖 AIMate 全局样式。
- [x] 调整工作区侧栏、模板卡片、工具栏，以及全屏创建、生成、编辑界面的尺寸和间距。
- [x] 用桌面与窄屏浏览器检查关键页面、交互和控制台。
- [x] 运行类型检查、完整单元测试和 PPT 冒烟测试；核对没有改动后台调用或数据结构。

## 决策

- 原型同时提供深浅色变量；沿用 AIMate 当前主题状态切换，仅在 PPT 作用域内映射到原型色值。
- PPTX 页面自身使用模板的颜色与字体；原型视觉变量只影响应用外壳。

## 主要差异与处理

| 部位 | 原差异 | 处理 |
|---|---|---|
| 配色与字体 | 通用应用蓝色强调色、Geist 字体和表面色直接进入 PPT 页面 | PPT 作用域映射原型的深浅色、紫色强调色及中英文系统字体栈；PPTX 画布保留模板颜色与字体。 |
| 工作区 | 侧栏为内嵌圆角卡片，内容边距较大，底部工作区信息不靠底 | 侧栏改为通栏分隔、固定宽度并靠底显示信息；内容密度按原型收拢。 |
| 模板中心 | 桌面仅三列，搜索框占满整行，卡片封面文字与标签重叠 | 桌面四列、搜索框限宽、标签在上且标题在封面底部。 |
| 新建流程 | 全屏阶段比原型宽，内容字体与间距偏大，推荐写法缺示例 | 阶段内容宽度与两栏比例对齐，面板间距收拢，补原型示例框。 |
| 生成与编辑 | 生成栏和编辑栏偏宽，编辑工具固定占右栏 | 生成栏按原型收窄；编辑器缩略图栏、浮动工具与进度状态对齐原型。 |
