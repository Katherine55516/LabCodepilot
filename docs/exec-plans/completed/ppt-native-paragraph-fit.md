## 约束与决策

- 保留现有 DAG、原生 PPTX 的图片/图形、用户页数和模板字体；不让模型返回坐标、字号、换行位置。
- 对没有换行空间的槽位要求单行简短内容；模板中已有多段的文字框按其段落数填入不同且有来源支持的要点。来源不足不得重复或编造。
- 文字适配与段落数由代码决定；模型只在原 content 节点内做一次有界语义重写。适配仍失败则质量门禁阻止发布。
- 旧项目的单字符串槽位继续可读；新模板保真项目使用结构化段落。
- 对原生多段文本，人工与 AI 的对象编辑均校验段落数量、label/body 结构；编辑器传入逐行文本时服务端按模板段落恢复结构。
- 模板自身的小字号补充说明保留小字号，但不会承担正文要点。模板允许换行时由原生文本框按固定字号换行；禁止换行时内容合同按宽度限制在一行。

## 验收

- 截图涉及的模板第 3 页三个列表框保留 2、3、3 条非空段落，标题 run 加粗、说明 run 沿用常规字重。
- 模板第 4、5 页的单行框不溢出，页内相同角色字号一致，小字只用于模板补充说明。
- 导出后的 shape 数、图片 hash 和字体仍与模板合同相符；简体、繁体与英文自检通过。

## 验证结果

- `selftest-ppt-template-fidelity.mjs`：原生列表段落、粗细体、项目符号、固定字号、简繁英内容、编辑与导出全通过。
- `selftest-ppt-semantic.mjs`、`selftest-ppt-structured.mjs` 与 `npm run typecheck` 全通过。
- 15 页真实 Cowork 导出：第 4 页三个列表框为 2/3/3 条；各页 shape 数与模板映射相同，图片 SHA-256 均相同，未出现 Unicode replacement character；浏览器伴随预览 15 页没有文本框滚动溢出。
- 质量状态为 `passed_with_warnings`，警告来自模板内低分辨率装饰图。模拟 LLM 只用于样例内容，没有调用外部模型。

## 边界

- 证据不足以填写模板规定的要点数时，现有有界修复会尝试重写；仍不足则质量门禁阻止发布，避免重复或编造。不会自动替换为另一张模板页，因为现有模板映射在项目创建时已确定。
