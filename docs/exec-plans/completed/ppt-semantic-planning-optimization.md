## 本轮范围与验收

1. Markdown、粘贴和现有文件提取结果构造成有类型的原子块；保留标题层级、列表、表格、代码/ASCII 图以及来源位置。小块只在相邻且结构/主题相容时合并；大块优先在结构、段落、句子边界拆分。
2. 每个 chunk 有稳定 ID、父级主题、语义类型、话语角色、来源 segment ID、估算 token 数和视觉候选；实现高优先级主题覆盖映射，不把 chunk 直接等同于一页。
3. 大纲输出保留原有 `section/title/focus/refs`，增补 Brief、故事弧、页面 role/question/supportingPoints/visualIntent/density。用户编辑大纲后，下一步内容生成使用已确认内容重建页面约束。
4. 逐页 Prompt 读取 Brief、整稿叙事、选中 chunk 和页面约束，要求 message-first 标题及“主张、机制、证据、启示”层级；只允许来源支持的数字、实体和结论。
5. 视觉意图仅映射现有九类 layout 和现有 image/chart/table/shape block；不增加 renderer 几何类型。无可信数据时不生成图表数值。
6. QA 输出覆盖、数值忠实度、相邻页重复、文案照搬和文字密度的指标/问题；确定性硬错误继续阻止发布，审稿模型仍只报告 missing/repeated/conflicts/unsupported。
7. 自检覆盖小块合并、大块完整切分、来源 ID、跨章节边界、长文档输入、回归以及可打开 PPTX。

## 边界外的文档建议

完整文档提出独立的 Brief/Story/Fact Synthesis/Visual Intent/Editorial Rewrite 模型阶段、持久化新 DAG 节点、架构图等新视觉对象、模板 slot 映射、UI 深度选项、按模型路由及局部自动重写。这些需要改变现有工作流、数据契约或界面。本轮只保存与现有节点兼容的语义数据及视觉意图，并在完成报告中逐项列出未覆盖部分和后续方案。

| 后续项 | 需要的改动 | 建议验证 |
|---|---|---|
| 独立 Brief/Story/Fact/Visual 节点 | 新 DAG 节点、持久化状态、失败恢复和模型轮次 | 比较生成时长、覆盖率和事实错误率 |
| 超长文档的全量规划 | 分层检索或 map/reduce 规划，而非单次 28k 字符上下文 | 以 80k 字粘贴及多文件输入测试召回率 |
| 新视觉对象与模板 slot | 扩展 IR、Render Tree、PPTX 导出和模板映射 | 预览与导出逐页视觉一致性 |
| UI 深度选择和局部自动重写 | 新交互、局部命令、版本冲突与增量重算 | 同时编辑、撤销重做和跨设备恢复 |
| 真实模型与 Cowork 端到端质量验收 | 使用生产模型、远程容器和真实模板运行样本集 | 内容完整度、导出质量、耗时、成本 |
