## 决策日志

- 2026-09-23：保留现有 DAG、IR/Render Tree、原生 PPTX 导出、模板字体和用户确定的页数。Codex 的 PPTX 查看器不在本仓库控制范围内，因此以模块 Render Tree 生成逐页 PNG 供可靠查阅；图片不通过重建形状替换。
- 2026-09-23：模板槽位的既有 `role` 保持兼容，新增语义 `purpose` 与配对 ID；说明长度限制按原槽位文字与几何信息计算，短标签不强制扩写。

## 验收标准

1. 目标模板右侧卡片的三个原生 PNG 在生成的 PPTX 中保持原字节，逐页预览呈现深色卡片。
2. 页面要点的可见说明是一句来源支持的解释；短标签、封面及极小文本框不因最短长度限制被误判。
3. 内容检查作用于最终绑定的 `slotTexts`，一次局部重写仍留在原 content 节点，未增加 DAG 节点。
4. 简体中文、繁体中文、英语文本与原模板字体策略一致，文字不溢出，原有自检通过。
