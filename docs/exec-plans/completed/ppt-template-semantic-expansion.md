## 详细设计与验收

1. 为每张源页记录标题/正文/列表/标签槽位、可承载的语义单元、图片与图解特征、方向性风险、适用页面角色和可用布局变体。版式目录进入持久化 `templateFidelity`，同时供大纲与调度使用。
2. 内容页映射采用内容角色、视觉意图、容量、源页使用次数和邻近视觉相似度共同评分；封面/结尾仍只用一次，禁止相邻同源和近距离周期性复用。
3. 首次使用源页保留原版；重复使用时分配有明确 ID 的安全几何/媒体变体。只有对象可安全重排时才使用派生布局；方向性图解保持坐标关系。导出继续检查形状数、媒体与字体保真。
4. 在现有 outline 节点中增加来源密度和主张独立性反馈；在现有 QA 中记录来源不足、未引用内容页和相邻/跨页重复风险。用户确认的页数不自动改写。
5. 覆盖短模板容量不足、方向性图解、不同角色和密度的版式选择、10→100 页、固定资源不丢失及实际 PPTX 导出。
