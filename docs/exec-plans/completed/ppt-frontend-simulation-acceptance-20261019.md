## 按钮与工作流矩阵

| 范围 | 必须检查的行为 | 通过标准 |
|---|---|---|
| 首页/库 | 搜索、筛选、排序、收藏、置顶、文件夹、多选、Shift、移动、删除、Esc、回收站 | 实际点击和请求一致；选中操作条可达；删除任务与删除成品独立 |
| 三入口 | Prompt、粘贴、文件、附图、编辑导入 | 真实表单、文件选择和来源参数；不同入口使用同一读取流程 |
| 模板 | 预览、上传、兼容性、原页数、固定对象、更新版本 | 不因模板页数覆盖用户页数；只发送选中对象ID |
| 模型设置 | LLM选择、高级执行策略、角色路由、模型列表加载/刷新/缺失 | 关键错误可见；无效配置不能继续；输入不丢失 |
| 读取 | 手动读取并估算、输入变化失效、页数调整、三档深度重读、恢复检查点 | 先读取再估算，调整后才生成大纲；复用同一projectId |
| 大纲 | 精炼指标、标题/正文修改、锁定、局部重组预览/应用、容量错误、确认 | 不绕过门禁；编辑和页数保留；应用前不替换原稿 |
| 生成 | 真实事件形态的模拟流、开始/完成页、文字增长、跟随/手动浏览、暂停/恢复、断流、后台任务 | 未开始页不冒充已生成；重复快照不重置浏览；同ID恢复 |
| 生成中AI | Ctrl+Enter、Enter换行、固定范围、队列状态、关闭重开 | 内容不丢失；范围与提交参数可核对；短屏按钮可达 |
| 编辑器 | 文本选择/编辑、字体字号、几何、表格、图片裁剪、图表/代码/公式、撤销/重做、版本 | 画布和提交命令一致；无误触几何修改；数学/原生对象保留 |
| 局部AI | 翻译、扩写、参数、候选对比、应用、丢弃、质量失败 | 使用模拟候选但真实组件交互；应用前不覆盖，门禁失败不发布 |
| 发布导出 | 待修复预览、正式导出禁用、修复后发布、导出入口 | 不接受的草稿不能正式导出；模拟成功仅验证前端状态与请求 |
| 导航/适配 | Home、Back、离开确认、桌面/短屏/窄屏、宿主导航、重复操作 | 未保存输入先确认；已持久任务保留；无阻挡、溢出或控制台错误 |
