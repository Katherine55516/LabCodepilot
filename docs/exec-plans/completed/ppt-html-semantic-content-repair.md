## 根因与验证

- 旧 HTML 提取会压平 `h1–h6` 结构。语义切片模块原本存在，但标题路径丢失后，跨小节召回与页级事实归属不稳定。本轮源文件得到 103 个语义 chunk，没有孤立或超长 chunk。
- 旧模拟内容把相邻 chunk 的句子独立填入各文字框，忽略模板一组标题、解释、图解标签之间的关系；自动截短还可能留下语法完整性不足的短语。本轮在模拟响应中逐页策划图解和卡片，并让模块检查相同问题。
- 49 页输出没有确定性质量硬错误；49 页 PPTX 均非空白，每页原生形状数与所选模板页相等，222 个图片形状的二进制内容保留。导出的 PDF 为 49 页，已检查整稿缩略图和问题页的全尺寸渲染。
- 相关 `selftest-ppt-semantic`、`selftest-ppt-template-fidelity`、`selftest-ppt-template-scheduler`、`selftest-ppt`、`selftest-ppt-report-qa` 均通过。模板自身的 100 条低分辨率小图/图标提示和 1 条正文小于 18 pt 提示仍保留为警告；本轮遵从模板保真，不替换它们。

## 验收标准

1. HTML `h1–h6`、列表和代码的结构进入语义索引；语义块能保留章节路径与来源引用。
2. 页面主张、标题、子标题、卡片和说明对应同一语义单元；概念和样例分开标注，不出现无依据的邻段拼接。
3. 模板文本槽位没有残句、错误的标签/说明配对、错位遮挡；变体选择先保证组件及其文字的相对位置。
4. 按模块页数估算重跑，质量门禁没有硬错误；逐页检查渲染，并记录真实 LLM 与本地模拟/容器执行边界。
