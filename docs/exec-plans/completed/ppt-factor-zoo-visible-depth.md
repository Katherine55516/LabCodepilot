## 详细设计与验收

1. 修复 page recommendation 将源文件名当作 overview 意图的问题；显式概览 prompt 仍支持压缩。用户确认页数保持优先。
2. 长章节至少按内容成本获得建议页数；短章节保留，并将根级介绍分配到封面。
3. outline 所有合法 refs/chunkRefs 保留；非法引用过滤。
4. 窄而多行的解释组件归类为正文；真标签保留。富来源模板正文使用容量与深度目标双约束；极短通用填充语判错。
5. QA 统计原生可见内容组；隐藏 takeaway 不满足可见支持，preserve 模式不能制造导出器忽略的假修复。
6. 整稿 critic 获得完整有界可见文本、本页来源代表段及必需细节；关键章节未映射在严格模式阻断。
7. 针对以上边界运行回归；重跑模块 routes→ingest→estimate→outline→content→review/repair→export→publish（仅模拟 modelCall），保存过程及实际原生输出。
8. 对照逐节覆盖与公式/数据边界；不将字数、通过门禁等同于来源完全覆盖或真实 LLM 效果保证。
