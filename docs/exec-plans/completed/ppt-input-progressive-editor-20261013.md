## 七点问题与改进方案

1. **输入中图片和图表不能丢失。** Prompt、粘贴文字都必须可粘贴、拖放和选择 PNG/JPG；附件不能仅在 paste 模式发送。嵌入 Markdown/HTML 的图片、Office 和 PDF 中的图片都纳入同一来源媒体目录，保留位置与说明，供规划分配和正文绑定使用。HTML 内嵌 SVG、Excel 原生 chart、PDF 矢量图表不能仅依赖 raster image 提取。无法解析的外链或本地图片引用要明确报告，并允许附图匹配，不能默默跳过。
2. **草稿预览必须完整，按页推进。** 用户截图显示标题/眉题字形裁切、媒体边缘截断。检查共享 SVG 渲染的尺寸、文字行框、图片 fit 和 native 几何，不能靠隐藏溢出来掩盖。依据 `../../../../AIMate_PPT_Gamma_Template_Generation_Teardown.md` 第 179–196、803 行及 `gamma_deep_learning_study/generation_retry_samples.json`：已完成卡保留，当前卡出现结构/标题再写入内容，后续卡尚不存在。主画布只显示已开始页并保持滚动阅读；规划列表可列出待生成标题，不显示整套未填模板。预览只展示已取得的内容，不制造打字动画冒充模型 streaming。
3. **组件位置随内容自适应。** 只有标题加单一 table/image/chart 的页面，组件在标题以下可用内容区域水平、垂直居中，保留图片纵横比；多组件按内容和说明安排。已由用户明确编辑的几何位置优先，避免生成规则覆盖手工拖动。
4. **修改要求需要可操作的聊天面板。** 面板采用固定标题、可滚动主体和固定操作区；在短窗口和 390px 窄窗口内可见提交/关闭按钮。显示初始需求、已发送修改及系统处理结果，保留草稿和冻结范围，生成进度不能覆盖输入。历史为空时也不能让空白区把 composer 推到屏幕外。
5. **每页内容充实且不重复。** 删除“完整来源细节见本页备注”“完整表见备注”等可见占位文案；来源、表格、图表必须实际可见，notes 不能替代正文。写作契约要求按页面问题给出有依据的机制、证据、限制或用途；资料不足时使用输入范围允许的解释，禁止编造数字/研究结论。内容不足的页合并/调整，内容超量则按语义拆页；不要为填满页面重复写 description。
6. **续页使用同一标题，末页有结束语。** 自动容量拆分不能附加“续”“续 2”“continued”等；内容分片仍保留完整原题。生成最后一页加入“感谢观看”或“Thanks for watching!”（按稿件语言），与结论正文同时存在，不将模板原有结束页变成普通薄页。
7. **页面 topic 不自动配中英双语。** 根据实际输入文字中各语言的可见篇幅确定主要语言，忽略代码、URL、文件路径和图片 base64；仅图片输入使用图片说明。自动标题、章节和眉题使用该语言，规划和写作共享同一判断。规范化已有的明确平行翻译标题；技术缩写、专有名称、人工锁定标题和正文双语事实不被误删。主要语言也用于末页结束语。测试英文为主夹少量中文、中文为主夹英文、日/韩文字、图片说明与代码噪声，检查最终页面标题及内容保真。

## 验收标准

- Prompt、paste 和 file supplement 图片都进入服务端来源目录；PNG/JPG 可作为源文件；重复图片按内容去重；缺失引用可追溯。
- DOCX、XLSX、PDF、HTML 至少覆盖图片和表格；XLSX 原生 chart 与 PDF 矢量图表有可见内容或明确可操作错误。
- 生成主画布保留已完成页和当前页，pending 页不呈现空模板；完成页面立即出现真实文字/媒体。
- SVG 草稿与编辑器文本/图片完整；检查宽度、高度、字体和 clip，截图人工复查。
- 单组件相对标题以下区域居中，用户几何不被覆盖。
- 短窗口、桌面和移动视口的修改面板可以滚动、发送、关闭并查看对话。
- 自动续页标题无续字样；末页有结束语；不再生成备注指引占位文案。
- 自动页面 topic 使用输入主要语言；少量另一语言不得改变判断，正文和人工锁定标题保真。
- 运行项目 typecheck/unit、相关 PPT 领域 selftests、PPT 浏览器回归和 smoke；导出与截图取证并在此记录真实结果和限制。

## 实施结果

1. Prompt、paste、file supplement 共用粘贴/拖放/选择入口，并都提交图片；PNG/JPG 可直接导入。服务端解析 DOCX 正文/页眉媒体、XLSX 图片和原生 chart、PDF 图片和矢量图、HTML PNG/SVG。原生 Office chart 经 Office→PDF 保留为图像。文件补充段落使用 S 编号，媒体 refs 同步重映射，避免与主文件段落混淆。来源媒体按内容去重，裸文件名、Markdown/HTML 图片引用按附件名匹配，失败显示 required warning。用户入口最多 16 张，来源目录最多 64 张，有字节预算。
2. 内容页按阅读顺序生成，完成真实结构化内容后立即提交本页预览；主画布保留已完成页和当前页，pending 页面不显示整套空模板。媒体/来源检查仍有界并行。模型适配器当前按页返回，不模拟 token 打字。SVG 改为外层 SVG 缩放和正常像素 foreignObject，原生文本框预留实际字形高度。
   - 2026-10-26 合并进选项 D 主线时（Fable 决定）：内容页的模型调用恢复有界并发（≤3），只把“按阅读顺序”保留在提交上——写完的页等前面各页提交、失败或暂停后再提交预览。见 [ppt-integration-option-d-mainline-20261026](../active/ppt-integration-option-d-mainline-20261026.md)。
3. 单一表格/图片/图表及简短说明在标题下的可用区域居中。来源 canvas 避开保留的全部前景图片，手动几何优先。
4. 修改面板固定标题和底部按钮，主体/历史可以滚动，显示初始需求、用户修改及处理结果，草稿和冻结范围继续持久化。
5. 新增可见备注替代文案硬错误，进入本页 writer repair；写作契约要求来源支持的具体解释，并保留现有防重复、防编造和可见内容门禁。
6. 自动容量续页保留原标题；末页按语言显示“感谢观看”或“Thanks for watching!”，总结正文保留。
7. 中英/日/韩文字按近似可见宽度计数（CJK 1、Latin 0.58），排除代码、路径、文件名、URL 和图片数据。页面 topic 的决策独立于旧正文语言提示，并在 brief、planner、writer 和最终 materialization 中一致；明确的平行翻译标题、章节和眉题只保留主要语言。保留技术缩写和专有名词，人工锁定标题与正文双语证据不被误删。“可持续”“业务延续”等真实词语不会被续页规则误改；自动结束语仍可编辑。

测试采用现有 Node 22 和随应用提供的 Python。TypeScript/Tailwind 扫描、webpack watch 和生产文件追踪排除生成目录；Playwright readiness 使用健康接口。性能采样确认整包图标导入造成模块编译和 GC 开销，加入 Next 16.2.1 支持的按需导入配置；修正 PostCSS 在默认 Turbopack 模式下的路径解析。生产构建的 NFT 初始追踪跳过动态工作目录全量 glob，静态模块追踪和显式 external 依赖 includes 保留。离线 UI/构建测试用临时本地字体响应，未改变产品字体配置，未提交字体文件。
