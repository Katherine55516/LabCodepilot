## 决策日志

- 2026-09-28：沿用现有 outline/content/quality DAG。创建时用确定性问题清单预规划短输入，outline 节点再由现有 LLM 细化；这可让默认页数在用户调整前基于规划而非字符数产生。
- 2026-09-28：预规划只包含可回答的问题、通用结构和证据缺口，不把内部公司数据或示例当事实。最终页数仍由用户设置优先。
- 2026-09-28：上传 PPTX 的原生文本样式与字体优先；自建版式由确定性 typography controller 统一行距。低于舒适阈值的模板样式记录风险，但不擅自改坏原模板。
- 2026-09-28：前端原有字符数估页会覆盖服务端推荐，现将未手动调整的页数留给服务端决定，解析文件后同步推荐理由；明确写页数和 `＋/－` 仍为用户决定。
- 2026-09-28：短但含事实的粘贴文本或文件继续按来源语义结构估页；通用问题清单只用于无来源的短 prompt，避免把一个事实扩成多页空泛内容。

## 本轮实施内容

1. 短 prompt 的意图分类、Brief 问题清单、证据缺口、语义单元成本估页；简体中文、繁体中文和英文问题清单。文件在 ingest 后重新按真实来源估页。
2. `pointBudget` 随页面角色、密度和分布变化，Writer 直接收到目标数量与视觉字范围；平衡页也检查过长 point，详细页检查整体支撑不足。连续四页高密度触发大纲修订提示。
3. 自建版式的行距及段距进入 Render Tree、SVG 预览和 PPTX 输出；QA 用同一容量估算检测溢出。原生 PPTX 导入段落行距用于预览并保留导出原样。
4. 模板槽位容量优先于通用 point 预算，避免文字加长破坏原版式。

## 未纳入本轮的架构变更

- 独立的前置 LLM Brief / Semantic Expansion / Page Estimator 节点会改变现有创建与 outline DAG。当前用确定性预规划给出初始建议，并让现有 outline 模型细化；若要让模型在用户选页数前深度扩展内容，需要另行设计异步预规划与确认流程。
- 在线研究、学习式页数/排版偏好、自动拆合页和 speaker notes 分流不属于这轮现有 workflow 内优化。

## 验收

- 短 prompt 在估页前有可持久化的内容计划和语义单元，估页不直接依赖字符长度。
- 不同角色的 point 数量与长度不同，检测缺少论据和过长说明。
- 自建版式预览与 PPTX 使用同一行距，自动设置不低于 0.95；用户显式设置可覆盖。
- 回归测试通过，保持模板字体和现有 Run/DAG/Event 接口。
