## 设计与验收

- 数字绑定原文语境；ordinal 仅在明确编号位置豁免，不忽略所有个位数。保留符号/单位；无确定支持时报告定位，不推断外部事实。
- source ID 不自证内容正确；结构义务不由 omissions 豁免；公式说明中英文识别。词汇检查仅保守信号，不冒充语义证明。
- 修复执行所属层允许操作，锁定/已接受页不动；新增问题与同类问题变差均回滚，保留 before/after。
- templateComponentProfile 版本化，保留原生保护区、媒体来源、重复组和角色容量；不同模板同一算法。
- 三组件使用共享 RenderTree，preview/PPTX/PDF 同源；本批不引入整页缩放。
- 离线源产物回放与人工 fixture 分别标注；涵盖中文/英文/双语、数值/表格/公式/关系/媒体。
- 验证新专项、已有 PPT 自测、npm run test；若修改前端呈现，dev + CDP + smoke。

## 后续边界

联合页数规划、更多布局、整页缩放、模型视觉评审与真实模型基线为后续阶段，本批先提供已验证容量与契约，不需要 API key。

## 验证与决策记录

- 35 项 PPT 自测全部通过；npm test：2808 通过、1 skip；11 项现有/新增 PPT 浏览器检查通过。视觉修复后受影响专项再次通过，新增组件/数学两项再验通过（唯一浏览器用例 12 个）。
- 生产 exporter 四页组件稿重新打开与实际 PDF 验证 passed；6 个点卡片的 XML 顶对齐、左对齐和无继承主题效果通过。原来源与模板 SHA256 未改变。
- 视觉复查发现并修正：共用父 nodeId 的片段编辑会替换正文、布局白名单遗漏、白色图标缺对比载体、Office 卡片默认居中/阴影、短公式被拉伸。新增布局仍在已有面板操作。
- Node 18 的 SQLite ABI 不匹配是环境错误，改用现有 Node 22.22.0；没有改依赖。M5 模拟 writer 的裸页码改成明确“第 N 页”，未放宽事实门禁。
- 三份历史模拟 writer IR 保留 blocked（33/33/35 hard errors），不冒充真实模型基线或本批成功生成。页数联合分配和 Gamma 密度实证不在本批完成范围。
