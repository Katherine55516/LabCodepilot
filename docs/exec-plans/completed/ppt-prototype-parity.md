## 详细设计

1. 工作区使用原型中的标题、侧栏、工具栏、页签、卡片和新建方式弹窗。
2. Prompt、粘贴文本和导入文件使用原型中的全屏分步流程；粘贴文本继续支持剪贴板图片。
3. 任务中心、模板中心和生成监视器使用原型中的页面结构与动作名称，并连接现有真实接口。
4. 已生成项目先打开原型式项目详情抽屉，再进入全屏编辑器。
5. 编辑器保留对象级 IR、命令日志、撤销重做、发布和导出能力，同时按原型组织顶部栏、页面栏、画布和工具栏。
6. 基于上一版更新使用原型中的三步流程，仍由真实版本接口提交。

## 验收标准

- 页面标题、按钮名称、主要布局、弹窗和步骤顺序与原型一致。
- 所有可见动作连接真实行为，不使用无反馈的占位按钮。
- 既有后端架构与数据模型无回退。
- `npm run typecheck`、`npm run test`、PPT 后端自检、PPT E2E 和构建通过。
- 通过真实浏览器检查关键页面与交互，控制台无新增错误。
