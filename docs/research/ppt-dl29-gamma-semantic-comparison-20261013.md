## 可观察的语义模型

Gamma 的页级单位是一个读者判断，通常由 2–4 个并列语义块支持。标题与块内容共同说明证据、条件、配置或比较，不需要再读一段“本页将介绍”的元叙述。其数字被赋予语义角色，例如 2–4 是层数、5–20 是集成规模、0.02–0.06 是弱信号范围。

测试稿已有来源 ID、类型化对象、主讲归属、备注合同、原生表格/数学与校验能力，但执行中仍偏向“来源单元—单页”映射。公式是一种表达而非独立叙事目的，比较表是一组候选与共同维度而非任意可抽取行，阶段/流程是带顺序或并行关系的整体。需要在规划前明确这些关系，随后再分配版式。

## 语义分割与排布

1. **边界过细**：第 8、10、20、22、23、29 页都缺足够独立增量信息。保留来源唯一性不等于每个来源必须一页；合并应在真实字号/容量内完成。
2. **边界过粗**：第 19 页约 173 个英文词一段解释 batching，与其他极短页形成不均衡。应把必要条件组织成关系明确的可读块，不把一句话机械拆成步骤。
3. **比较边界丢失**：Qlib 单行表失去横向比较功能；不能仅依据选中行准确就认定语义完整。
4. **跨节错位**：ALSTM 数学补漏落在总结之后；稳定来源章节应约束插入点，最后总结不再引入无关新事实。
5. **可见结构不足**：第 23 页“Explains the operational constraints…”是生成过程摘要而非具体约束。图标/背景存在不能替代模型—输入—适用条件的结构。
6. **语言策略失配**：英文正文中残留 34 个汉字，尤其标题和目录。metadata 修复也应携带同一语言合同，不能为缩短标题恢复另一语言。
7. **数学视觉失配**：第 16 页水平拉伸，第 29 页黑公式/深蓝底对比不足。公式树完整只能证明符号没被改，不能证明视觉可读。
8. **来源标识侵占**：多页底部重复显示“完整来源见备注”，部分文案本身被截断。备注入口应由 UI/文件 notes 提供，主稿无需每页新增横条。

## 改进优先级和验收

| ID | 改进 | 验收 |
|---|---|---|
| S1 | 比较集合的摘要约束 | 多行比较不得退化成一行仍称总览；原 cells/风险保留，真实过滤除外 |
| S2 | 叙事章节与总结边界 | 补漏插入所属章节，稳定 ID/归属不变，无总结后的孤立主体事实 |
| S3 | 页级读者问题与关系单元 | 分配多个相关短单元，定义/公式/条件、对应矩阵、并行/流程保留正确关系 |
| S4 | 公式自然比例与对比 | 原字号/字体保真，原生数学可编辑；真实渲染不横向拉伸、不黑字深底 |
| S5 | 全阶段语言与可见文案 | 英文策略不恢复中英标题，正文不讲生成过程，不反复添加来源横条 |
| S6 | 围栏中的结构识别 | ASCII 架构/流程不是程序代码；code=omit 时仍保留其语义与关系 |
| S7 | 真实模型失败恢复 | 只重试失败步骤、保留成功页；格式/传输与内容问题分别诊断，质量门禁保留 |

### 正文与整稿审查追加修复

审查确实拦截了原稿将“更可能”升级为“唯一 source of truth”、AIJSX 内部来源 ID 上页、无依据性能推断等问题。自动 critic 仅修改对应页，其他页保存。测试也暴露两个通用缺陷：

1. `Textbox x/y/w/h` 是非执行的几何对象清单，却被当成程序代码隐藏。现严格匹配整个坐标清单并转为完整原生数据表，保留对象、坐标和尺寸；混有程序语句时仍为代码。正反例及真实 gamma.md 字段绑定均验证。
2. 生成说明与真实冻结来源共享 `sourceArtifactNodes` 容器，critic 错误冻结正文槽位；且非绑定来源页的修复 prompt 未显式给出最终 schema，模型可返回已退役的正文槽位，造成空白候选回滚。现仅真实来源对象/精确摘录冻结载体，生成说明页明确继续用 `sourceCommentary` 输出完整必要正文。拒绝候选仍不覆盖原页，所有门禁保留。旧 LLM 响应只读回放仍显示旧 schema 无法完整入页，因此没有把该诊断宣称为通过，而是用新 schema 重新测试真实路径。

同时加入内部来源编号可见文案拦截、writer 推断限定提示，以及审查实例实际表行数量与首尾标签，减少续表行数误读。完整串行套件再次运行结果：2887 通过、1 跳过、0 失败；新增提取/修复专项也通过。
