大纲的关键特征：

- **卡片内容就是页面内容。** 每张卡片已是压缩后的 3–8 条要点、编号步骤或一句话论断（第 4、12、15、19 张是论断卡）。后续“写幻灯片”只是把卡片内容排进版式，不再决定讲什么。
- **按想法切分，而不是按标题切分。** 11 节 → 19 张：第 1 节拆成 4 张（两种范式 / 生产模型 / “搜索廉价，验证才是一切” / 看别处效应）；第 7 节拆成关卡清单 + 一句论断；第 9 节拆成角色 + 谱系；第 11 节拆成代码示例 + 挖掘循环；目录被丢弃；引言里“与教程 14 并读”变成结尾卡。
- **事实原样保留**：0.3–0.8、0.02–0.05、√N、2,000、ICIR≈0.3、10^6、约 3,700 个交易日、15 年、八道关卡全部在。
- **双语合并成一行**：“English | 中文”，中文侧更短；不再把两种语言的整段都放上页面。
- **代码不贴原文，而是解释**：Python 例子变成“raw = -ret5 / rank(20 日平均成交额)，再做截面排名 · 仅为示例”。
- **页数由内容决定**（19），不是用户先给上限、系统再测量、再请求授权。

## 4. 每个问题的改进方案与取舍

1. **私有元数据**：长度类校验只针对用户可见文本；内部字段（reason、focus 草稿等）在进入时截断，不再作为失败条件。最优：统一在入口处规范化，规则表里删掉对内部字段的硬拒绝。
2. **ID 账本**：两种做法——(a) 继续让模型返回 ID 账本，代码补回退（现在的路线，失败类型会继续出现）；(b) **账本由代码维护**：模型只写“这张卡讲什么”（要点 + 引用的来源段落），代码根据引用自动得出覆盖情况，不要求每个 unit 恰好一次。最优：(b)。
3. **阶段太多**：Gamma 一次写出“已压缩的卡片内容”，后续只排版。最优：把“语义大纲 + 容量 + 物化 + 编辑选择 + 分配 + 压缩 + 缩减”合并成**每个主题一次“写卡片”调用**（代码定卡片数，即刚上线的按主题配额），之后只做逐卡适配。
4. **模型审核门槛**：最优：门槛只保留**确定性检查**（数字、公式、术语是否来自原文；必须保留的定义/条件是否出现；卡片是否放得下）。模型审核改为可选的事后建议，不阻塞。
5. **修复环**：卡片彼此独立后，修复只在单张卡片内进行（一次重试 + 确定性收缩），不需要全局修复环和治理器。
6. **页数授权**：最优：页数由测量结果自动决定（像 Gamma），用户可以给“最多 N 页”，超出时自动合并相邻卡片或压缩，而不是停下来要求授权。
7. **双语**：最优：采用 Gamma 的“English | 中文”合并写法作为双语默认（一条要点两种语言），原文双段全文只在“保留原文”模式下使用。
8. **非确定性**：并行结果一律按输入顺序合并（Promise 结果数组），不在回调里累加。
9. **策略一致性**：已修；新设计里策略省略的对象根本不进入卡片候选。
10. **耗时**：卡片按主题并行，调用数约等于主题数（12_ml_quant 约 11 次 + 少量重试）。
11. **逐字容量**：散文由卡片写作压缩，只有表格、公式、代码、图片作为原样对象测量。

## 5. 建议的新大纲设计（参考 Gamma）

1. **设置**：读取输入一次，推断默认值：语言（中文 / 英文 / 双语）、文本处理（压缩 / 保留原文 / 扩写）、模板。不问页数；可选“最多 N 页”。
2. **主题与卡片数（代码）**：按来源结构分主题（现有语义大纲可复用），用 C1 测量每个主题需要几张卡片。
3. **写卡片（模型，每个主题一次，并行）**：返回该主题的 N 张卡片，每张 = 标题 + 内容块（要点 / 步骤 / 论断 / 原样对象引用：表格、公式、图片）+ 每条要点引用的来源段落 ID（溯源，不是分区）。
4. **确定性检查（代码）**：数字与术语出自原文、必须保留的定义/条件出现、原样对象完整、每张卡放得下（测量）；不合格的卡片单独重试一次，仍不合格就按测量收缩。
5. **大纲审阅（用户）**：合并 / 拆分 / 重排卡片、给单张卡片写指令、改模板；与 Gamma 一致。
6. **生成**：逐卡排进模板版式（内容已压缩，写作阶段只做版式映射与润色）；渲染与质检保持不变。

保留：模板保真与渲染、来源读取与警告、C1 测量与按主题配额、失败追踪与对话框、cassette 回放。
