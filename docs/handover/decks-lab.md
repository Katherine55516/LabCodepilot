# Decks Lab：长文档、模板解析、组件与媒体编排（技术交接）

> 产品思考见 [docs/insights/decks-lab.md](../insights/decks-lab.md) · 模块总览见 [decks.md](decks.md)

本文件整理 Decks 第三轮的全部新增逻辑：PDF 解析 → 语义切分 → 图与内容的关系 → 媒体编排 → 模板解析 → 模板组件识别 / 排布 / 匹配 → 引擎串联 → 渲染导出 → 测试台。所有规则都是**通用**的，不针对任何一个模板写特例；用 9 份模板（4 份 Gamma 导出 + 5 份企业模板）和 1 篇 21 页论文验证。

## 0. 链路总览

```
PDF / Markdown ──import-pdf / blocksFromMarkdown──▶ SourceBlock[]（标题/段落/表格/图）
   └─chunking──▶ SourceChunk[]（语义块 + 卡片预算 + 图的归属）
   └─media-relations──▶ 图的类型 / 系列 / 相关度

PPTX 模板 ──template-pptx──▶ 主题（背景/文字/强调色/卡片色/字体）+ 装饰图池 + 版式节奏 + Logo
   └─template-components──▶ 图形组件（单元 + 共享核心 + 图片位 + 图案周期）

规划（outline）：带 [C#] 语义块、[F#] 图、组件可容纳的项数提示 → 每张卡引用 sources / figures
   └─groundOutline：校验与补全引用、图只用一次、按相关度排序
构建（每张卡）：
   1 组件匹配 layout-match（按阅读顺序预先决定，保证多样性）
   2 写作：原文依据 + 图 + 组件指令 → blocks（applyComponent 兜底）
   3 媒体编排 media-plan：按文字占比决定图数量/版位/尺寸；模板横条；节奏
   4 检查/润色：溢出时先撤横条，再撤装饰，图保留、缩短文字
渲染 CardView / 导出 export-pptx：同一套几何（组件排布 component-layout 共享）
```

## 1. PDF 解析（`src/lib/decks/import-pdf.ts`）

- pdfjs-dist（legacy build，服务端 external）读取带坐标的文字；`getOperatorList` 后从字体名判断粗体/斜体。
- **行重建**：同基线分组 → 宽间隔切分片段（栏间距、表格单元）→ 按栏归组；**每栏单独**取主字号、去掉上标（脚注标记）。
- **阅读顺序**：通栏行把页面切成带，带内先左栏后右栏。
- **去除**：页眉页脚/页码（多页重复的边缘行）、脚注（页面下 25% 的小字）、图内标签、未分类小字；每类计数并保留样例（测试台可见）。
- **标题**：粗体 + 短 + 编号（`2.1.` → 2 级，`A.` → 1 级）或字号 ≥ 1.1 倍正文；编号必须带字母（排除 “2 3” 这类脚注号）。
- **题目/作者**：第 1 页最大字号为题目，题目与第一个标题之间为作者（数字标记去除）；作者行仍作为图区域的上边界。
- **段落**：行距跳变、列表项、缩进（仅在上一行结束时）分段；跨栏/跨页续接；断词连字符重连；TeX 分离重音字符合成（`J ¨urgen` → `Jürgen`）。
- **图表**：`Figure N.` / `Table N.` 起始的说明，连续同字号行合并；表格为说明上方/下方的多单元行（数字保留）；图为说明上方到最近“实体文字”之间的区域，**渲染整页后裁切**（矢量图也能取到），再裁掉白边；未完成句子中的图延后到段落结束（浮动体）。
- 依赖 `@napi-rs/canvas`（pdfjs 的可选依赖）渲染；不可用时保留图说明并给出警告。

## 2. 语义切分（`chunking.ts`）

1. 按标题建章节；参考文献/致谢等后置内容丢弃（计数），附录保留但权重 0.3，摘要为前置内容（0.5）。
2. 目标块大小 `T = clamp(正文字数 / (卡片数−1), 700, 4500)`；只有标题的小节并入下一节；同一顶层章节内的薄小节合并（≤ 1.25T）；过长的块在段落边界平均切分（`(1/2)`）。
3. **图的归属**：被引用最多的块（`Figure 4`、`Fig. 4`、`Figures 2–4`）；平手归图注所在块；无引用归图注所在块。
4. **卡片预算**：`(字数 + 350×图数)^0.8 × 类型权重`，最大余数法分配，总和 = 卡片数 − 1。
5. 规划输入 `plannerDigest`：每块 `[C3] 路径 · 类型 · ≈n 张` + 图 `[F4] Figure 4 (diagram, wide, series S2): 说明`，按比例裁到 60k 字；写作输入 `sourceExcerpt`：被引用块的全文（≤ 7000 字）。
6. 规划回复 `sources` / `figures`；`groundOutline` 校验 id、缺失时按词重叠补引用、图全局只用一次、按相关度排序；模型完全不给图时按归属自动配。

## 3. 图与内容的关系（`media-relations.ts`）

- **类型**：图注关键词（插画/照片 > 图表 > 示意图 > 截图，越具体越优先）+ 像素统计（白底比例、颜色数、彩度）：白底少的“图表”判为截图。
- **系列**：编号相邻（≤2）、类型相同、形状相近（宽高比对数差 < 0.3）、同归属块或图注相似 → 同一 series；只有同系列（或同类型同形状）才能同卡成组。
- **相关度**：卡片文字是否引用（+1）、是否属于卡片引用的块（+0.4）、图注与卡片词重叠（×1.5）。

## 4. 媒体编排（`media-plan.ts`）

- `fill` = 正文行数 ÷ 无图时卡片容量（1 = 满）。
- **数量随文字量**：fill ≤ 0.30 最多 3 张，≤ 0.55 两张，否则 1 张；多余的“延后”并记录原因（弱相关 / 与主图无关）。
- **一张图**：图表/示意图完整显示（contain）并有可读性下限（侧边 ≥ 42%，宽图且文字少则放顶部）；照片/截图形状与版位接近时铺满（cover）；版位宽度按图的宽高比填满高度，但不压缩文字所需宽度；图注随图。
- **多张图**：同系列组成图组，高度按剩余空间（≥ 150px）。
- **装饰图**：随 fill 缩小（0.5 → 0.42 → 0.34），fill > 0.85 不放；有模板时**按模板节奏**（模板那一页没图就不放）。
- **模板横条**：内容图占了版位、模板节奏该位置有图、扣除横条后的文字占比 ≤ 0.85 时，加 15–20% 高的模板图横条；溢出时首先撤横条。
- 模板装饰图挑选：与版位形状最接近、与角色一致、最近两张卡未用过、使用次数少者；封面优先用模板第 1 页的图并沿用其构图。

## 5. 模板解析（`template-pptx.ts`）

- **背景**：按 母版 → 版式 → 幻灯片 的绘制顺序取最上层的整页填充：纯色、渐变（色标平均）、背景图（`p:bg` blipFill 或整页图片）。半透明整页色块视为**遮罩**：背景色 = 图片平均色与遮罩色按透明度混合。整页图只在少数页（≤ 50%）出现 → 封面照片（节奏记为 background 并入图池）；多数页出现 → 底纹（取平均色）。
- **文字色**：字数最多且对比度 ≥ 4.5 的颜色，优先中性色（彩度 < 0.2 且占比 ≥ 25%）。
- **强调色**：优先“饱和色”（彩度 ≥ 0.15；形状填充按面积、彩色文字按字数），否则最常用填充；忽略 Office 默认配色（4472C4 / ED7D31 …）。
- **第二强调色**：不同色相的候选，否则取装饰图平均色。**卡片色**：与背景对比 1.05–1.8、能承载正文（≥ 4.5）、中性或同色系的填充。
- **字体**：中文按 `a:ea`，未声明则继承主题字体（`+mj-ea` / Hans 脚本字体）；标题（占位符或 ≥ 24pt）与正文分别统计；补齐衬线/无衬线回退栈。
- **装饰图池**：≥ 4% 面积的位图；排除带超链接的图（厂商角标）、小图标、SVG/EMF、透明形状碎片、细长条形、纯色块、被覆盖的底纹。
- **Logo**：同一张小图（按内容哈希）出现在 ≥ 40% 幻灯片的同一角落 → 写入页眉页脚对应位置。
- **版式节奏**：每页装饰图位置（left / right / top / background / none）。

## 6. 模板组件（`template-components.ts`）

识别步骤（逐页）：
1. 拍平形状树（组合按 `chOff/chExt` 映射坐标），读出图片 / 形状 / 线 / 文字（字号、颜色、粗细、对齐、锚点）。
2. 排除标题（最大字号或标题占位符）、宽的导语段落、贴边大图。
3. **条目标题**：≥ 2 个同字号同颜色的短文本；阅读顺序 = 视觉行（容差 14% 高度）→ 从左到右；有编号按编号；条目横坐标两两不同且上下交替 → 沿条带从左到右。
4. 每个条目：下方较小字号的正文、最近的编号（`1` / `01`）、**附属元素**（与条目框间距 ≤ 3%W / 4.5%H 且不大于条目 1.6 倍：卡片底框、图标、编号框、连接线）；叠放碎片（IoU > 0.7，如四叶草）和跨多个条目的元素（时间轴竖线、底板）为**共享核心**。
5. **图片位**：与某条目横向重叠 ≥ 60%、上下间距 < 12% 的照片 → 该条目的图片位（原文的图可放进来）。
6. 质量：标题框重叠 → 误识别丢弃；条带过薄且无正文无编号 → 图例丢弃；单元互相重叠 → 固定项数。
7. **图案周期**（motif）：共享图片沿条带方向（单调前进的轴）做自相关，找到“平移后与自身差异最小”的位移（低于平均误差 60%，再 4 倍精度细化），并记录内容边界与每周期条目数。
8. 所有几何相对组件外框归一化；字号以模板 pt 保存。

## 7. 组件排布（`component-layout.ts`）

`arrangeComponent(comp, n, items?)` —— 任何项数（2–8）都规整排布：
- **竖列 / 之字形竖排**（每个视觉行一个条目）：`flowColumn` 按每项文字估算高度依次排列，间距相等，保留左右交替与单元内元素偏移，卡片底框随高度伸长，贯穿竖线拉伸。
- **单行横排**：保持模板总宽，n 个单元等宽等距，单元内部等比缩放（图片不变形）。
- **重复步长模式**（等距直线/斜向阶梯 p=1，之字形 p=2，网格 p=列数，含错落）：识别相邻单元位移的最小周期 p，第 k 项 = 第 k−p 项 + 一个周期位移；p=1 时用平均步长保证严格等距。
- **网格**（无周期时）：模板列数、单元尺寸与间距，最后一行居中，按列错落偏移保留。
- **图案组件**（链条、箭头条、整图时间轴）：分段拼接，接缝都在环的中心；开头用原图（干净起点）、中间用整周期平移副本、结尾用整周期副本（相位一致时）或**镜像原图**（干净终点）；增减项数都适用；导出用原生 `srcRect` 裁切与 `flipH`。
- 环形（叠放碎片）与无图案的中心构图：固定项数；项数不符时渲染退回主题样式网格（**不截断条目**）。
- 字号随宽度缩放（`widthScale`），组件高度上限 400px（竖向扩展 520px）。

## 8. 内容 ↔ 组件匹配（`layout-match.ts`）

- 规划阶段：把模板组件可容纳的项数告诉规划模型（并列内容按这些项数写成“短标题：一句说明”）。
- 每张卡（按阅读顺序预先决定）两种模式：**条目模式**（2–8 个短要点）与**图模式**（≥ 2 张同系列/同类型的图 → 带图片位的组件）。
- 打分（统一规则）：基础 1；项数一致 +0.3，伸缩每差 1 项 −0.15；正文槽与说明匹配 +0.4（缺正文 −0.1）；编号 ↔ 顺序内容 +0.3；环形 ↔ 概览 +0.2；图模式 +0.6；未用的模板照片 −0.1；标题/正文超出槽位容量 −0.3/−0.2；重复使用 −0.25/次、紧邻重复 −0.4；阈值 0.9；最多约 70% 的卡用组件。
- 写作模型收到组件指令；没照做时 `applyComponent` 把列表类块替换为组件（图由引擎放入图片位）。

## 9. API 与测试台

| 路由 | 作用 |
|---|---|
| `POST /api/decks/lab/analyze?kind=source\|template&fileName=` | 解析（原始字节） |
| `POST /api/decks/lab/rechunk` | 不同卡片数下重新切分 |

| `POST /api/decks/import`（.pdf） | 正式导入走同一路径 |

页面 `/decks/lab`：模型选择、上传、切分表（预算/图/页码/去除样例）、图（类型/系列/归属）、模板主题/字体/节奏/图池/Logo/组件、生成结果与每张卡的媒体决策、模板覆盖率。
